# תכנות מתקדם ב-C++ — אפליקציית לימוד

אפליקציית לימוד אינטראקטיבית המבוססת על מצגות הקורס של אפרת עמר, המרכז האקדמי לב.

> **מפתחים וסוכני AI:** לפני שנוגעים בקוד — קראו את [`AGENTS.md`](AGENTS.md).
> שם נמצא התיעוד ההנדסי המלא: ארכיטקטורה, מערכת העיצוב, ההבדלים בין גרסת המובייל
> לדפדפן, מה עובד, מה עדיין חסר, מלכודות ידועות וכללי העבודה בגיט.

## הרצה

```bash
npm install     # פעם אחת
npm run dev     # מרים את האפליקציה על http://localhost:5173
```

לבנייה לגרסת ייצור: `npm run build`, ואז `npm run preview`.

## מה יש כאן

| יכולת | פרטים |
|---|---|
| **קומפילציה נפרדת אמיתית** | כל קובץ `.cpp` נשלח בנפרד ל-g++ 13.2 (Wandbox) ומתקמפל לבד, ואז מקושר — בדיוק כמו Visual Studio. לכן מתקבלות **שגיאות לינקר אמיתיות** (`undefined reference`) ו**שגיאות הכללה מרובה אמיתיות**. דורש אינטרנט. |
| **עטיפה חכמה** | קטעים מהמצגת שאינם תוכנית שלמה (רק הגדרת מחלקה, או שתי שורות שימוש) נעטפים אוטומטית ב-`int main()` עם ה-`#include` החסרים. האפליקציה **מציגה מה בדיוק נוסף** ומאפשרת לראות את הקובץ המלא שנשלח. |
| **עורך מרובה-קבצים** | לשוניות `.h` / `.cpp` / `main.cpp` עם הוספה, מחיקה ושינוי שם. תבנית "פרויקט מחלקה" יוצרת את שלושת הקבצים עם השלד הנכון. `Ctrl+Enter` מריץ. |
| **דיאגרמות זיכרון** | Stack ו-Heap מונפשים צעד-צעד, מסונכרנים עם שורת הקוד הרצה. |
| **עוזר AI — שלושה ספקים** | Claude, ChatGPT או Gemini. כפתור ✦ ליד כל קטע פותח שיחה שמקבלת את תוכן העמוד ואת הקטע המדויק. |
| **חידונים ותרגילים** | תשובות, התקדמות ופרויקטים נשמרים ב-localStorage של הדפדפן. |
| **מצב כהה/בהיר** | כפתור בסרגל העליון. |

## מפתח API לעוזר ה-AI

עוזר ה-AI הוא היכולת היחידה שדורשת מפתח. **כל השאר — כולל הרצת הקוד — עובד בלעדיו.**

באפליקציה: ⚙ (הגדרות) → בחר ספק → הדבק מפתח → "בדוק מפתח" → "שמור".
בכל ספק יש מדריך השגה מלא עם קישורים ישירים, וניתן לשמור מפתח לכל השלושה ולהחליף ביניהם.

| ספק | עלות | איפה משיגים |
|---|---|---|
| **Google Gemini** | ✓ **רמה חינמית, בלי כרטיס אשראי** — הכי מתאים לסטודנטים | [aistudio.google.com/api-keys](https://aistudio.google.com/api-keys) |
| **Anthropic Claude** | בתשלום · נדרשת טעינת קרדיט מראש | [console.anthropic.com](https://console.anthropic.com/settings/keys) |
| **OpenAI ChatGPT** | בתשלום · נדרשת טעינת קרדיט. **מנוי ChatGPT Plus אינו כולל API** | [platform.openai.com](https://platform.openai.com/api-keys) |

המפתח נשמר **רק ב-localStorage של הדפדפן** ונשלח ישירות אל הספק. אין שרת ביניים.

### בחירת המודל — אוטומטית לגמרי

אין בחירת מודל ידנית, בכוונה. ספקים מוציאים מודלים משימוש ומשאירים אותם ברשימה:
`gemini-2.5-flash`, למשל, עדיין מופיע ב-ListModels אבל מחזיר
`404 — no longer available to new users` למפתחות חדשים.

לכן האפליקציה:

1. שואלת את הספק אילו מודלים המפתח מורשה להריץ
2. מדרגת אותם לפי העדפה
3. **מנסה אותם אחד-אחד בבקשה זעירה** עד שאחד באמת עונה
4. שומרת את הבחירה; אם מודל שמור מפסיק לעבוד — היא מזהה, מנקה ובוחרת מחדש בשקט

גם פורמט המפתח לא נבדק מול קידומת קבועה — מפתחות Gemini חדשים מתחילים ב-`AQ.`
ולא ב-`AIza`, וכל בדיקה מקומית כזו רק חוסמת מפתחות תקינים.

## בדיקה שכל הקוד בשיעור באמת רץ

במצב פיתוח נחשף `window.__dev`. הדבק בקונסולת הדפדפן כדי לקמפל את **כל** בלוקי
הקוד הניתנים להרצה בשיעור ולקבל דוח כשלים:

```js
const d = window.__dev, out = [];
for (const ch of d.LESSONS[0].chapters)
  for (const s of ch.sections)
    for (const b of s.blocks)
      if (b.kind === 'code' && b.runnable) {
        const p = b.files?.length
          ? d.wrapProject(b.files)
          : { files: [{ name: 'main.cpp', code: d.wrapSnippet(b.code, b.prelude).code }] };
        const r = await d.runProject(p.files, { stdin: b.stdin });
        if (r.buildFailed) out.push([s.id, b.title, r.compilerMessage.slice(0, 160)]);
      }
console.table(out);
```

## הוספת שיעור חדש

1. צור `src/content/lessonNN/` עם קבצי פרקים המייצאים `Chapter`.
2. צור `index.ts` שמייצא `Lesson` עם `ready: true`.
3. החלף את ה-`stub` המתאים ב-`src/content/index.ts` בייבוא של השיעור.

הסכימה המלאה של הבלוקים מתועדת ב-`src/types/content.ts`.
